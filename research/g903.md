# Logitech G903 LIGHTSPEED (HERO)

First findings for the G903, gathered to add a second device type to
Loginux. Labels follow [hidpp20-lighting.md](hidpp20-lighting.md). Every
request sent so far was a getter.

## Identity (live, 2026-10-22)

- **On its cable:** USB `046d:c091`, named "G903 LIGHTSPEED Wireless Gaming
  Mouse w/ HERO". Interface 0 carries the mouse reports and interface 1 the
  keyboard reports used for macros. Interface 2 carries HID++ (vendor usage
  page `ff00`) and nothing else, so access to it exposes no input.
- **Through its LIGHTSPEED receiver** (`046d:c539`): the Linux DJ driver
  shows the mouse as `046d:4087` "G903 LS", in slot 1 (`HID_PHYS` ends in
  `:1`). That node also carries the mouse's movement and button reports.
- HID++ 4.2 in both connections.

## Lighting (live, by cable)

- `0x8071` reports two clusters with four effects each, and no `0x8081`
  per-key lighting.

  | Cluster | Location | Effects (index: ID) |
  | --- | --- | --- |
  | 0 | `0x0001`, primary | 0: off, 1: Static `0x01`, 2: `0x03`, 3: `0x0a` |
  | 1 | `0x0002`, logo | the same four |

  Solaar names `0x03` "Cycle" and `0x0a` "Breathe". The capability and period
  words of `0x0a` (`c001`, `1e0b`) match the G316's. (live for the IDs;
  static for the names)
- `0x8100` onboard profiles reads mode `01`. In Solaar's terms that is
  onboard mode: the mouse's stored profile decides DPI and lighting.
  Whether a host can still take the lighting effects through `0x8071`
  software control while the mouse stays in onboard mode is unknown.

## What Loginux needs for the G903

- **Cluster lighting.** The colour is set per cluster with `0x8071` SetEffect
  (Static, persistence `01`), not per key with `0x8081` frames. Definitions
  need a zone kind that names a cluster.
- **A small map.** The editor draws a board from key rectangles. A mouse
  definition can use the same rectangles to draw the two zones.
- **Access.** A udev rule for interface 2 of `046d:c091`, like the G316's,
  exposes no input. The receiver path needs the DJ child node, which also
  carries mouse reports, plus handling for a sleeping or out-of-range mouse.
- **A watched test first.** Take software control, set Static on the logo,
  look, and hand back, all in RAM. Separately, find out what onboard mode does
  to that claim.
